# Hangman Basic

A simple command-line Hangman game built with Python. Guess the hidden word one letter at a time before running out of lives!

## ✨ Features

- Random word selection
- Interactive letter guessing
- Six lives per game
- ASCII-art graphics
- Win and lose messages
- Option to play multiple rounds

## 🛠️ Tech Stack

- Python 3
- Python Standard Library

## 📂 Project Structure

```
Hangman_Basic/
├── Hangman_code.py   # Main game logic
├── Hangman_words.py  # Word collection
├── Hangman_art.py    # ASCII art and game visuals
└── README.md
```

## 🚀 Getting Started

**1. Clone the repository**

```
git clone https://github.com/Numan-Ahmad-Khan/Hangman_Basic.git
```

**2. Navigate to the project directory**

```
cd Hangman_Basic
```

**3. Run the game**

```
python3 Hangman_code.py
```

*Windows users can run `python Hangman_code.py`.*

## 🎯 How to Play

1. Start a new game from the main menu.
2. Guess the hidden word one letter at a time.
3. Correct guesses reveal letters; incorrect guesses cost a life.
4. Reveal the complete word before losing all six lives to win.
5. Play another round or exit.
